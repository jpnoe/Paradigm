# Paradigm: Beyond Binary Computing

This repository contains public prior art and foundational documentation for a non-binary, negentropic computational architecture operating on the complex plane. 

## Included Documentation
* [Beyond Binary Specification](./beyond_binary.md): The core whitepaper detailing continuous-state electrical cells, torsional logic, Möbius data types, and topological solvers.
* **Archival Artifacts**: Includes an immutable PDF record and release metadata establishing public domain dedication under the Creative Commons Attribution-ShareAlike 4.0 International license.
